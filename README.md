# MICASE
## Code relating to the Michigan Corpus Oral History dataset (no data included)

This repository is for processing code to generate a static website from the 
Michigan Corpus of Spoken Academic English (MICASE) dataset. The data is not 
(yet) included pending permission, but the code will be developed in public
here whether or not the data becomes available.

This is a personal project by Martin Holmes and John Thiels.
