For search and browse, these are non-exclusive; in other words, if you search for near-native-speaker, you'll get all discussions which involve a near-native-speaker. All of these must be staticSearch meta tags. The original site has a slightly different set or organization of these for the browse and search pages, but I see no reason for the difference, so we should simply have a single search/browse page which allows use of all the filters with or without a search string.
    
We also add Document Type so that you can search info pages, but transcripts would be selected by default.
